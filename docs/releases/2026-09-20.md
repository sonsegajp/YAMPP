# YAMPP v0.1.0 - 2026-09-20

First public Windows x64 release of Yet Another Melee PC Port, a PC port based on the Melee decompilation. Includes rollback Online, custom Options menus, Workshop, and optional Akaneia fighters, stages and music. Akaneia installation starts from your local official archive; room-join downloads require confirmation.

## Play

Download the Windows ZIP from [Releases](https://github.com/sonsegajp/YAMPP/releases), extract it completely, and run **Play YAMPP.cmd**. Setup requires your own Melee NTSC-U 1.02 / GALE01 revision 2 disc image. Windows x64, a Vulkan-capable driver and the Visual C++ x64 runtime are required. Startup follows the original opening movie into the title screen; A/Start skips the movie.

No disc images, extracted game assets, installed mods, saves or private configuration are included. For initial Akaneia installation, place the official archive in `user/imports` and follow the [installation guide](../akaneia-install.md). Missing room-required content can still download directly from official GitHub after confirmation. Its fighters, stages and music can be toggled in Online > Mod Browser > Mod Manager (X).

## Included

- Rollback Online rooms, typed room names, required-content confirmation, results and rematches.
- Profile username and local picture, additive costume slots, Mod Browser and Mod Manager.
- Controller mapping, input visualization, tap-jump toggle, and 4:3 / 16:9 options.
- Selective Akaneia fighters, stages and music with content reload in the same window.
- Workshop, custom-music tools, setup instructions, UI screenshots and dependency credits.

## Included fixes

- First-run setup unpacks your disc before any gameplay launch-plan checks. Extraction does not initialize the renderer.

- Corrected an AX ADPCM boundary bug that repeated music and caused sharp sample jumps on Akaneia's GameCube stage. The matched capture fell from 18,501 large adjacent-sample jumps to zero. Green Hill was also checked; see [audio evidence](../audio-validation.md).
- Included all 51 referenced Akaneia stage files, fixing the missing arena title table and Village scenery. Older local tester installs should disable and re-enable Akaneia once to rebuild their cached import.
- Corrected distant ReDead texture palettes and improved four-player rendering performance.
- Updated the Controller option artwork, Online presentation, Saria's Song label and project branding.

## Known limits

Occasional loading/render stalls can still cause short audio gaps. Profile pictures remain local. Linux has compile validation, but no included Linux binary or hardware-gameplay claim. Physical four-port adapter behavior still needs hardware verification. Online tests cover specific builds and scenes, and do not guarantee every connection or arbitrary mod. The audio-fixed build has offline capture validation; the latest impaired-connection Online evidence uses the immediately preceding native build. See [tester notes](../tester-build.md) and [Online evidence](../netplay-validation.md).
